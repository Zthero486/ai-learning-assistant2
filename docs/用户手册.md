# 四史学习助手 · 用户手册

> 面向日常使用者（学生）的图文操作手册。所有截图均来自软件真实运行画面。
> 安装与启动见 [README](../README.md)，部署到公网见 [部署到公网](部署到公网.md)。

---

## 1. 登录与选课

首次启动进入登录页。内置演示账号 `demo / demo123`（含历史事件、史料、题目的示例数据，可直接体验全部功能）。

![登录](images/manual/01-登录.png)

登录后选择要学习的课程——**党史 / 新中国史 / 改革开放史 / 社会主义发展史**（简称「四史」）。一个账号绑定一门课程，后续所有页面（教材、时间轴、题目、错题）都只显示所选课程的内容；侧栏的课程徽标可以一键切换。

选课入口在侧栏左上角的徽标，或侧栏底部「切换课程」。

## 2. 学习看板

打开软件的首页：汇总今日待复习、错题概况、最近知识点与任务，是每天开工的入口。

![学习看板](images/manual/21-学习看板.png)

## 3. 教材目录

左侧是所选课程的章节树（来自四本官方简史的目录，共 32 章 193 节），右侧显示该节**教材原文**：

- 「本章正文」固定为章下第一项，展示整章内容；
- 右上角 **A- / A+** 可调正文字号（记忆在本地，下次打开保持）；
- 扫描版教材经 OCR 切分入库，个别节切不出正文会有兜底提示。

![教材目录](images/manual/22-教材目录.png)

**AI 联动跳转**：在与 AI 对话时让它「把某段原文标出来」，AI 会直接把页面翻到对应章节，并用高亮标出原文所在段落（见 [AI 助手](#9-ai-助手) 与 [联动跳转截图](images/manual/13-联动跳转-史料笔记.png)）。

## 4. 四史时间轴

按年份纵览所选课程的历史事件，支持按时期筛选、点击查看详情、右侧「新增事件」补充自己的时间线。

![时间轴](images/manual/23-时间轴.png)

## 5. 史料笔记与史实要点

- **史料笔记**（`/materials`）：上传史料文件（最大 200MB）或摘编要点，形成自己的史料库；支持 Markdown 编辑与导出 PDF。
- **史实要点**（`/knowledge`）：以卡片管理重要史实，每条可关联来源史料与关联题目，一键「AI 出题」即可围绕该要点生成练习。

![史料笔记](images/manual/24-史料笔记.png)

![史实要点](images/manual/25-知识点.png)

## 6. 复习任务

把「要复习什么」变成卡片：每张任务卡记录目标、截止与完成状态，完成情况会汇入学习看板。

![复习任务](images/manual/26-复习任务.png)

## 7. 自测

自测页是**会话式**的：先组卷（可选范围与题量）→ 一次答一题 → 即时判分 → 结算页汇总对错，错题自动进入错题本。

| 组卷 | 判分反馈 | 结算页 |
| --- | --- | --- |
| ![组卷卡](images/manual/14-自测-组卷卡.png) | ![判分反馈](images/manual/15-自测-判分反馈.png) | ![结算页](images/manual/16-自测-结算页.png) |

支持单选题（点选即判）与简答题（对照参考答案自评）。AI 生成的题目会自动带上教材原文依据。

## 8. 错题本与间隔复习

错题本按课程分组折叠，首屏即可看到整体概况。复习排期采用 **FSRS 间隔重复算法**：答对间隔逐步拉长，连对 2 次或间隔 ≥21 天即「掌握出库」；未安装 FSRS 依赖时自动退回 1/2/4/7/15 天的阶梯排期，行为一致。

![错题本](images/manual/03-错题本.png)

「今日复习」页集中展示今天到期的卡片：

![今日复习](images/manual/04-今日复习.png)

每道错题可以请 AI 做**错因诊断**（六类错因：史实混淆、时空错位、概念不清、审题偏差、记忆模糊、材料误读），诊断结果记入错题卡，用于后续针对性复习。

错题本与史料支持**导出 PDF**，方便打印。

## 9. AI 助手

AI 能力可选配置（不配置也能用，自动降级为规则引擎；配置方法见 README「配置 AI」一节）。

**AI 对话**（`/ai`）：基于教材原文回答四史问题，回答带「出处」卡片，点击直接跳到对应章节并高亮原文。

![AI 对话](images/manual/06-AI对话.png)

**内嵌 AI**：自测页、错题本页等都内嵌了对话入口，学习过程中随时提问：

![内嵌 AI](images/manual/20-内嵌AI-自测页展开.png)

**浮动 AI**：全站右下角的悬浮球，任何页面都能呼出，可拖动，手机上自动全屏：

![浮窗 AI](images/manual/10-浮窗AI-错题本页.png)

**AI 能做的事**：

- 问答与讲解（引用教材原文，标注出处）
- 出题（单选/简答，直接进题库与自测页）—— ![AI 出题](images/manual/17-AI出题-自动开做.png)
- 写知识点、史料笔记、复习任务、历史事件
- 页面联动跳转（「翻到第三章第二节」）
- 错因诊断与学习建议
- 记住你的学习偏好（用户画像记忆库，可在对话中说「记住我偏好…」）

AI 修改类操作有单次对话的写入上限，避免误操作刷库；删除类操作需要你在对话里明确指示。

## 10. 数据同步与备份

多台设备之间通过 Git 式快照同步学习数据（uuid 键控，冲突按时间合并）。侧栏底部「数据同步」进入。

![数据同步](images/manual/27-数据同步.png)

> 注意：同步会把含密码哈希的账号 JSON 推送到同步仓库，建议使用**私有**仓库作为同步枢纽。

## 11. 手机 / 平板访问

电脑启动后，侧栏「手机访问（扫码）」会给出局域网地址与二维码；同一 Wi-Fi 下扫码即用。在外面也能用——软件内置 Cloudflare 免费隧道一键开公网地址（详见 [部署到公网](部署到公网.md)）。

![手机访问二维码](images/manual/07-手机访问二维码.png)

手机上同样的功能、自适应布局；语音输入支持普通话与方言转写：

![语音输入](images/manual/08-语音输入-桌面.png)

## 12. 常见问题

| 问题 | 处理 |
| --- | --- |
| 界面显示「未配置 AI key」 | 软件自动降级为规则引擎，功能可用但无大模型回答；按 README 配置 `.env` 后重启 |
| 响应超时 | 主通道超时/限流会自动切备用通道，无需手动处理；若持续超时检查网络或换模型 |
| 扫描版教材某节没有正文 | OCR 切分限制，属已知现状；可用「上传史料」功能补该节内容 |
| 忘记密码 | 演示数据可用 `demo / demo123`；自建账号删库重建或让管理员重置 |
| 端口被占用 | 启动脚本会自动向后探测空闲端口，无需手动处理 |
