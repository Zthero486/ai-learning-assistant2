## 操作流程

```bash
# 1. 同步最新 develop
git checkout develop
git pull

# 2. 切分支（命名规范见 CONTRIBUTING.md）
git checkout -b feat/docs-user-manual

# 3. 写文档 + 截图
#    截图放 docs/images/ 下，命名用模块名：dashboard.png / materials.png ...
#    Markdown 里引用：![](images/dashboard.png)

# 4. 提交
git add docs/
git commit -m "docs: 新增用户手册（七个子模块图文说明）"
git push origin feat/docs-user-manual
```

然后到主仓库提 PR（流程同 T1），base 选 `develop`。

## 截图怎么弄（重要）

**用便携版 exe 截图，不要用 dev 服务器**——界面才代表最终交付形态。

1. 双击 `release/AILearningAssistant.exe`
2. 浏览器打开 `http://127.0.0.1:8000`
3. 先用 `python scripts/seed_demo.py` 灌演示数据，页面才不会空荡荡
4. 用 `Win + Shift + S` 截图，保存到 `docs/images/`
5. 截图前把窗口拉到 1440px 宽，保证清晰

## 写作要求

- **不要写"该模块用于管理用户的课程资料"这种空话**。写"点右上角『上传资料』→ 选择 PDF → 等待解析进度条走完 → 列表第一行出现新文件"。
