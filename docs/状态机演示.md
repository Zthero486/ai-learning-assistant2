# Agent 状态机 · 现场演示手册

> 一句话：AI 不是「一问一答」，而是 **接收需求 → 自己调工具 → 独立质检 → 不达标就带着意见重做 → 达标才收尾**。

## 状态机长什么样

```
        ┌──────────────── 不达标（最多 2 次）────────────────┐
        ↓                                                  │
   ┌─────────┐      ┌──────────┐      ┌──────────┐          │
   │ act 执行 │ ───▶ │ review 审查│ ───▶ │finalize 收尾│        │
   └─────────┘      └──────────┘      └──────────┘          │
     模型自主调工具        质检员独立       输出答复            │
     （读/写数据库）       判「满足需求吗」                    │
        └──────────────────────────────────────────────────┘
```

- **act**：模型带着 25 个工具自主执行（查教材、读正文、建知识点、出题、建任务……）
- **review**：模型停手后，**另起一次调用**当质检员，输出严格 JSON `{done, gap}`；纯问答（没动工具）跳过审查，省调用
- **回流**：`done=false` 时把 `gap` 原文作为新一轮输入喂回去（最多 `MAX_REVIEWS=2` 次），防止死循环
- **finalize**：达标 / 审查次数用尽 / 轮次用尽 → 出最终答复
- **记忆**：对话结论可写入 `user_memory`，下次注入 system prompt，形成「学生画像」

## 方式一：脚本三幕（推荐投影演示，最稳）

```bat
python scripts\demo_state_machine.py           :: 三幕，1 秒跑完，不联网不花 token
python scripts\demo_state_machine.py --pause   :: 每幕按 Enter 再继续，按讲解节奏走
python scripts\demo_state_machine.py --live    :: 追加第四幕：真模型实跑（需联网 + AI key）
```

三幕分别是：

| 幕 | 演什么 | 屏幕上看什么 |
|---|---|---|
| 一 | 一次通过 | `act → review → finalize`，工具 1 次、质检 1 次、回流 0 |
| 二 | **不达标回流（重点）** | 第一版答复被判不合格，打印「★ 回流」和缺口原文，第二版才收尾 |
| 三 | 记忆沉淀 | `save_memory` 落库，末尾列出 `user_memory` 里的条目 |
| 四（`--live`） | 真模型 | 同样的事件流，模型换成 StepFun，约 5~10 秒 |

**为什么脚本版不会翻车**：模型与质检员都是脚本化的（预设输入输出），演示的是**状态机本身的逻辑**，与网络、API 额度无关。演示用的数据库是系统临时目录里的随机库，**不会动真实数据**。

讲解词（照着念）：
> 「第一幕是顺利情况。重点看第二幕：模型第一版只报了个进度，质检员判定没给出可执行的计划 —— 注意这里质检是一次**独立的调用**，不是模型自评。它把缺口原文喂回模型，模型第二轮才给出三天计划，这时才收尾。第三幕说明对话结论会沉淀进记忆库，之后排计划会带上你的画像。」

## 方式二：界面演示（手机/网页，最直观）

打开「AI 对话」（或任意页面右下角浮动 AI），问一句**需要多步操作**的话：

- 「看看我的学习情况，再按我的情况排一个三天复习计划」
- 「帮我读第三章第二节的教材正文，然后给我出 3 道单选题」

**观察点**：
1. 每调用一次工具就出现一行工具卡片（`find_node`、`get_node_text`、`create_questions`…），带读/写标记
2. 工具用完后出现一张**「质量自查」**卡片：`正在自查结果是否满足要求…` → 变成「自查通过」，或「未达标 + 缺口原因」
3. 未达标时下方会接着出现新一轮工具调用与答复 —— 这就是回流

**注意**：真模型的行为有随机性，界面演示可能一轮就通过、看不到回流。**要稳定看到回流，用方式一的幕二**。

## 方式三：逐事件探针（排查/讲解细节用）

需要看 SSE 原始事件（含回流喂给模型的缺口原文）时：

```bat
python scripts\probe_state_machine.py "帮我读第三章正文再出 3 道题"
python scripts\probe_state_machine.py "党史有几章" --no-write
```

服务需已启动（`release\AILearningAssistant.exe` 或 `uvicorn`）。它会实时打印 `[执行] / [审查] / ★[回流]` 与每次工具调用。

## 兜底与常见问题

| 场景 | 处理 |
|---|---|
| 现场没网 / API 额度用完 | 只跑方式一（默认三幕不联网），第四幕加 `--live` 才会联网 |
| 想在教室投屏，字太小 | 终端调大字号；`--pause` 每幕停住讲解 |
| 界面演示没出现回流 | 属正常（模型一次就过）；用脚本幕二补讲，或问更复杂的需求 |
| 想证明「不是演的」 | 跑 `--live`，并现场换一个问题；再跑 `python scripts\agent_eval.py` 看 11 个场景评分 |
| 想看写权限边界 | `--no-write` 只读模式；删除类工具在演示库里可放心试（临时库） |
