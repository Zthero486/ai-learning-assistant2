# 历史学习框架研究与软件改造方向

> 阶段：资料搜集 + 框架设计（未改代码）
> 日期：2026-11-05
> 用途：课设答辩的「设计依据」章节 + 下一阶段改造的施工图

---

## 一、为什么要先搭框架

目前软件的骨架是通用的：`材料 → 知识点 → 题目 → 练习记录 → 错题本`。
这套骨架换成任何学科都成立，历史只是换了个皮肤（字段叫 `course`、`era`）。

但历史学科真实的学习单位不是"一个知识点"，而是：

- **一个单元**（如"晚清时期的内忧外患与救亡图存"，含 3 课）
- **一条主线**（如"统一多民族国家的形成与发展"贯穿整个中国古代史）
- **一种能力**（如"给你两段互相矛盾的史料，你信哪个、为什么"）

学生复习时问的是"我这一单元过没过""我到底是记不住时间还是读不懂材料"，
而现在的软件回答不了这两个问题。这就是框架要补的地方。

## 二、查到的四类依据

### 2.1 课标：历史学科的五根支柱

《普通高中历史课程标准（2017 年版 2020 年修订）》与《义务教育历史课程标准（2022 年版）》
都把历史学科核心素养定为五个方面，且明确它们不是并列关系：

| 素养 | 定位（课标原文要义） | 在学习中的表现 |
|---|---|---|
| **唯物史观** | 诸素养形成的**理论基础** | 用生产力/生产关系、经济基础/上层建筑解释"为什么会变" |
| **时空观念** | 历史学科的**基本思维** | 把事件放回特定时间与空间框架，判断阶段特征 |
| **史料实证** | 认识历史的**必备方法** | 一分材料说一分话，辨真伪、辨作者意图、论从史出 |
| **历史解释** | 思维与表达的**外显能力** | 不只描述史实，还要揭示表象背后的因果 |
| **家国情怀** | 学科的**价值追求** | 对国家民族的认同感、责任感（多落在开放性试题的价值立意上） |

关键结论：**唯物史观是根，时空观念是坐标系，史料实证是方法，历史解释是出口，家国情怀是落点。**
所以软件里不能把它们做成五个平行的标签页，要有主从关系。

### 2.3 评价：能力是可以打刻度的

**学业质量水平 1–4** 是课标给出的四级能力刻度，也是考试的分水岭：

| 水平 | 能做什么 | 对应考试 |
|---|---|---|
| L1 | 辨识、提取史实 | 学业水平合格考前段 |
| L2 | 在特定时空框架下定位、描述史事 | **合格性考试**（毕业线） |
| L3 | 概括、说明，用史料论证观点 | 高考中档题 |
| L4 | 独立分析、论述，多角度解释与评价 | **等级性考试**（选考/高考） |

**《中国高考评价体系》"一核四层四翼"** 又给出另一组切口：
- 四层（考什么）：核心价值 → 学科素养 → **关键能力** → 必备知识
- 关键能力具体化为三项：**获取和解读历史信息 / 分析历史问题 / 历史探究**

> 对软件的意义：每道题除了"对错"，还应该有 `素养维度` + `水平 1–4`。
> 这样错题本能算出"你 L2 时空定位错了 7 次"，而不是只报一个正确率。

### 2.4 学法：有实证支持的有效做法

学生实际在用的方法（时间轴、思维导图、错题本、康奈尔笔记、艾宾浩斯周期）里，
哪几种真有效？认知科学给出了明确答案：

| 方法 | 证据 | 对软件的落地 |
|---|---|---|
| **检索练习**（先测再看） | Karpicke & Roediger (2008)：同等时间下测验组一周后保持率约为重复阅读组的 1.5 倍 | 自测优先于"再看一遍笔记"；知识点页要有"闭卷回忆"按钮 |
| **间隔重复** | Cepeda 等 (2006, 2008)：间隔安排显著优于集中突击；最佳间隔随保留期增长 | 错题不按"标记已解决"关闭，按 1/2/4/7/15 天排复习队列 |
| **交错练习** | Rohrer & Taylor (2007)：混合题型练习比集中同型练习迁移成绩高约 40% | 组卷默认跨单元、跨题型混排，而不是只练本课 |
| **精细加工 / 自我解释** | 生成"为什么"比记住"是什么"留存更久 | 简答题要求写"因果链"，AI 按因果完整性评分 |

另外两个历史学科特有的、网上教研文章反复强调的做法：

- **大概念统摄**：一单元提炼 1–2 个大概念（如"民族交融""大一统""盛世与危机"），
  所有零散知识点挂在这个概念下，先见森林再见树木。
- **问题链 / 情境化**：不是问"鸦片战争哪年"，而是给一段史料问"英国为什么选择鸦片"。

## 三、诊断：现在的软件缺三根轴

| 轴 | 现状 | 缺口 |
|---|---|---|
| **内容轴**（学什么） | `materials`（上传的文件）+ `knowledge_points`，`course` 是自由文本 | 没有教材层级，无法"按单元复习""看整册进度" |
| **能力轴**（练到什么程度） | `questions.type` 只有选择/简答；`practice_records` 只有 correct 0/1 | 没有素养标签、没有水平刻度，错题无法归因 |
| **方法轴**（怎么练才有效） | 有错题本、有任务、有时间轴 | 错题无复习调度；时间轴只展示不能练；组卷不交错 |

一句话：**现在是"存东西的柜子"，还不是"带着走的路线"。**

## 四、提议的框架：三轴一体

```
        ┌─────────────── 内容轴（骨架）───────────────┐
        │  册 Book → 单元 Unit → 课 Lesson → 知识点 KP  │
        │        每个单元挂 1–2 个大概念 + 时期          │
        └───────────────────┬──────────────────────────┘
                            │
        ┌───────────────────┴──────────────────────────┐
        │  能力轴（刻度）                                │
        │  五素养（唯物史观为根）× 水平 L1–L4 × 关键能力  │
        └───────────────────┬──────────────────────────┘
                            │
        ┌───────────────────┴──────────────────────────┐
        │  方法轴（节奏）                                │
        │  预习→建构→检索→诊断→间隔复习（闭环）          │
        └──────────────────────────────────────────────┘
```

### 4.1 内容轴：内置教材骨架 + 学生自建

- 内置《中外历史纲要》上下（20 单元 54 课）+ 选必三册（18 单元 48 课）的**空骨架**（只有标题，无正文）
- 学生导入的材料/知识点挂到具体"课"上；`course` 字段保留但降级为"时期"标签
- 每个单元有一张**单元学习页**：大概念 → 时间轴 → 史料 → 知识点 → 题目 → 掌握度

### 4.2 能力轴：可算的掌握度

- `knowledge_points` 增 `competency`（五素养之一或"综合"）、`level`（1–4）、`big_idea`
- `questions` 增 `competency`、`level`、`error_type`（答错时归因）
- 新增**素养雷达图**：五维掌握度 = 该维度题目的加权正确率 + 复习及时率
- 错题归因为四类：**史实记错 / 时空错位 / 史料解读错 / 表达不规范** —— 每类对应不同补救动作

### 4.3 方法轴：把"复习"变成有节奏的动作

```
新学（挂到课）
  ↓
建构（生成时间轴 / 大概念图）
  ↓
检索（闭卷自测，跨单元交错）
  ↓
诊断（错题归因到素养维度）
  ↓
间隔复习（1/2/4/7/15 天，答对升档、答错降档）
  ↓（回到检索）
```

首页看板从"统计卡片"变成**今日三件事**：今天该复习的 5 个知识点 / 该重做的 3 道错题 / 本单元还差哪一课没建。

### 4.4 AI 的新位置

现在 AI 是"万能问答 + 出题"。改造后应变成**框架内的助手**：

- 出题时注入：`大概念 + 素养维度 + 目标水平 + 史料` → 产出带标签的题（史料型选择题，而非问答）
- 批改时按"因果链完整性 / 史料引用 / 时空定位"三个维度给分，而不是打分
- 单元页一键"本单元大概念提炼 + 一句话主线"

## 六、范围收敛：改为服务中南大学"四史"课程

> 2026-11-05 晚，wjx 提出把范围缩窄到中南大学大三要修的"四史"课程。
> 下面这一节**取代**前面第五章的分期计划；第二～四章的中学部分保留，作为"为什么这样设计"的方法论依据。

### 6.1 制度背景（分级标注确定性）

| 结论 | 确定性 | 依据 |
|---|---|---|
| 高校必须围绕"四史"开设**选择性必修课**，确保学生**至少选修 1 门** | 已确认·国家政策 | 中宣部、教育部《新时代学校思想政治理论课改革创新实施方案》（2021） |
| 中南大学马克思主义学院自 **2021 年秋季学期**起开设《"四史"学习专题》公共选修课 | 已确认·中南 | 马院公告《学百年党史，开马院新局》原文："力争于 2021 年秋季学期开设《'四史'学习专题》公共选修课" |
| **大三**是四史教育的主要承接年级 | 已确认·中南 | 中南大学《关于组织学生参与"同上'四史'思政大课"的通知》：大一、大二随思政课集体收看，**大三、大四由学院自主组织** |
| 中南大学在超星平台有"四史课程（2025-2026-1）"，思政部开设，吴争春等 10 人团队 | 已确认·中南 | 超星慕课课程页 |
| 具体到电子信息类培养方案里"四史"占几学分、排在第几学期 | **未确认** | 公开网页无逐学期课表，需查教务系统 |

结论：**"四史"在中南是实打实的课，且落在大三**；但"必须修哪一门、几学分、什么考核形式"要你从教务系统确认——这直接决定下面的设计。

### 6.2 内容骨架：换成四本官方简史（章节数是硬的）

| 课程 | 读本（2021 年"四史"简史系列） | 结构 |
|---|---|---|
| 党史 | 《中国共产党简史》（人民出版社·中共党史出版社） | **10 章 70 节** |
| 新中国史 | 《中华人民共和国简史》（人民出版社·当代中国出版社） | **7 章 40 节** |
| 改革开放史 | 《改革开放简史》（人民出版社·中国社会科学出版社） | **7 章 44 节** |
| 社会主义发展史 | 《社会主义发展简史》（人民出版社·学习出版社） | **8 章** |

合计 **32 章、约 160 节**。相比中学五册 54 课，这套骨架更贴你的实际，体量也小得多，
一周之内可以把骨架全部灌进去。

四本书的章名本身就是现成的大概念：

- 党史十章：创建与大革命的洪流 → 土地革命的风暴 → 全民族抗日战争的中流砥柱 →
  夺取新民主主义革命的全国性胜利 → 新中国成立和社会主义制度建立 → 社会主义建设的探索和曲折发展 →
  伟大历史转折和中国特色社会主义的开创 → 把中国特色社会主义全面推向 21 世纪 →
  在新的形势下坚持和发展中国特色社会主义 → 中国特色社会主义进入新时代
- 新中国史七章按**五年计划式的时段**切分：1949—1956 / 1956—1978 / 1978—1992 /
  1992—2002 / 2002—2012 / 2012—2017 / 2017—2021
- 改革开放史七章按**"拉开大幕—全面展开—开创新局面—科学发展中深化—进入新时代—全面深化改革—高水平对外开放"**递进
- 社会主义发展史八章：空想社会主义产生和发展 → 科学社会主义创立 → 第一个社会主义国家建立 →
  一国到多国与苏联模式 → 中国共产党对建设道路的探索 → 世界社会主义的曲折与奋起 →
  中国特色社会主义开辟新纪元 → 中国特色社会主义进入新时代

### 6.3 关键发现：四史在时间上是**重叠**的

```
党史            1921 ─────────────────────────────── 2021
新中国史                    1949 ─────────────────── 2021
改革开放史                          1978 ─────────── 2021
社会主义发展史  1516 ────────────────────────────────── 2021
```

三条中国线在**同一根时间轴上叠着走**：同一个年份，四本书各讲一件事。
比如 1956 年——党史讲"八大"和《论十大关系》，新中国史讲"社会主义改造基本完成"，
社会主义发展史讲"苏共二十大与波匈事件"。

这是通用笔记 App 给不了的东西，也是这个软件最该做的差异化：**四史对照时间轴**。
点一个年份，四条线各自的事件同时展开；这既是最容易混的地方，也是最容易讲清楚"三条线如何互相解释"的地方。

### 6.4 能力轴要换：从"五素养"改成"思政课考法"

中学那套（五素养 + 学业质量水平）在四史课上对不上。思政选择性必修的考核是：

| 层次 | 题型 | 例子 |
|---|---|---|
| **史实识记** | 单选 / 多选 / 填空 | 遵义会议的时间与意义 |
| **时序定位** | 排序 / 年代判断 | 下列事件按时间排序 |
| **史论结合** | 名词解释 / 简答 | 简述家庭联产承包责任制的推行过程与意义 |
| **现实联系** | 材料分析 / 论述 | 结合材料，说明"中国共产党为什么能" |

所以能力维度定为四个：**史实识记 / 时序定位 / 史论结合 / 现实联系**。
五素养里的"唯物史观""家国情怀"退为**论述题的评分维度**，不再当导航轴用。

### 6.5 方法轴：三件套保留，加两个四史专用动作

- 保留：检索练习（先测再看）、间隔重复（1/2/4/7/15 天）、错题归因
- 新增：**四史对照时间轴**（同一时点多线并列）
- 新增：**会议 / 文件卡片**——时间 + 地点 + 核心决议 + 历史地位。
  四史里最容易考、也最容易混的就是这一批（一大、八七会议、遵义会议、七大、七届二中全会、
  十一届三中全会、十二大至二十大……），做成卡片比做成笔记有效。

### 6.6 改造清单（收敛后的 P0）

1. 新表 `syllabus_nodes`（自引用树：课程 → 章 → 节），内置四史 32 章约 160 节
2. `knowledge_points` 加 `node_id`（挂到节）、`exam_type`（识记/时序/史论/现实）
3. `questions` 加 `exam_type`、`book`（党史/新中国史/改革开放史/社会主义发展史）
4. `wrong_book` 加 `next_review_at`、`error_type`
5. 新页面：四史对照时间轴、会议卡片、章学习页
6. seed：四史骨架 + 关键会议 30 条 + 每章 3 道样例题
