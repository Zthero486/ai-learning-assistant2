**锁法要点（重要经验）**
- 不能用「盘根加 deny」——deny 会被子目录继承，把白名单目录一起封死（继承的 deny 排在继承的 allow 之前命中）。
- 正确做法：**从盘根移除广泛授权（`icacls X:\ /remove:g *S-1-5-11 *S-1-5-32-545`）+ 子目录显式 allow**。

**本机环境坑（沿用）**

- `New-Object -ComObject WScript.Shell` 被安全策略拦截。
